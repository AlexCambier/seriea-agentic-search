**[Open the interactive page](https://alexcambier.github.io/seriea-agentic-search/)**: https://alexcambier.github.io/seriea-agentic-search/

Click the picture or the link. GitHub shows index.html as code: the page itself opens at the link above,
published with GitHub Pages (Settings → Pages → Deploy from a branch → main → /docs).

- index.html: the whole page, a single file with no dependencies
- preview.png: the screenshot shown here, in the main README and in link previews

To change the page, replace index.html and push to main: the site updates in a minute or two.
